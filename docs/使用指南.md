# 使用指南

面向使用者的完整操作说明。如果你只想知道怎么开始，看 README 就够了；
本文档讲的是**怎么把它用好**。

---

## 一、快速上手（3 步）

### 第 1 步：装上去

**先拿到文件 —— 推荐直接下 ZIP**（走 codeload，国内比 `git clone` 稳）：

```
https://codeload.github.com/HuaXiLF/shenlun-trainer/zip/refs/heads/main
```

浏览器打开即下载，或：

```bash
curl -L -o shenlun-trainer.zip https://codeload.github.com/HuaXiLF/shenlun-trainer/zip/refs/heads/main
```

解压后把文件夹改名成 `shenlun-trainer`，然后复制进 skills 目录：

```bash
# Windows
robocopy shenlun-trainer "%USERPROFILE%\.workbuddy\skills\shenlun-trainer" /E

# macOS / Linux
cp -r shenlun-trainer ~/.workbuddy/skills/
```

<details>
<summary>想用 git clone 的话</summary>

```bash
git clone --depth 1 https://github.com/HuaXiLF/shenlun-trainer.git
```

`--depth 1` 只取最新版本，省掉历史，更快。
但 `git clone` 走的是 `github.com`，国内可能卡住 —— 卡住就回到上面的 ZIP 方式。

</details>

### 第 2 步：准备训练台账

```bash
cp 训练记录模板.md 训练记录.md
```

把它放在你平时的工作目录（Agent 的工作目录）下。之后每次批改会自动追加一行。

### 第 3 步：开练

对 Agent 说：

```
申论，练小题
```

它会从真题库里抽一道你**没练过的**小题，只给你材料 + 题干。

## 二、完整训练闭环

```
    ┌──────────────┐
    │ 申论，练小题  │  抽题，只给材料+题干，不给答案
    └──────┬───────┘
           ▼
    ┌──────────────┐
    │   你作答      │  手写 / 打字，掐时间
    └──────┬───────┘
           ▼
    ┌──────────────┐
    │  申论，批改   │  四段式批改 + 逐笔扣分 + 得分
    └──────┬───────┘
           ▼
    ┌──────────────┐
    │  改错 + 复盘  │  按"改进动作清单"改一遍
    └──────┬───────┘
           ▼
    ┌──────────────┐
    │  申论，进度   │  每 5 题看一次，确认薄弱环节
    └──────────────┘
```

### 关键：批改后一定要"改一遍"

批改的价值不在看懂，在**改对**。拿到批改后：

1. 看「**改进动作清单**」——按优先级排好了，先改第一项；
2. 看「**表述升级表**」——把「原表述 → 升级为」逐个替换掉；
3. 看「**改后示范**」——照着写出完整句子，不要只在心里想；
4. 把改好的版本存下来。

> ⚠️ **改稿铁律（重要，别踩这个坑）**
> 批改说「这句错了」= **把这句改对**，不是**把这句删掉**。
> 很多人收到批改后倾向"大幅删改"，结果把采分词和线索一起删没了，覆盖率反而下降。
> **字数没超就不要压缩** —— 200 字题写满 190—200 字是划算的。

## 三、命令详解

### `申论，练小题` / `申论，出题`

**默认行为**：
- 从 `corpus/国考题目汇总-2022-2025.md` 抽题
- **优先抽你没练过的**（查 `训练记录.md`）
- 题型默认按你的**弱项轮换**
- **只给**材料原文（可精简为关键段）+ 题干 + 要求 + 字数
- **严禁**在作答前透露答案、要点方向、踩分点

**点名题型**：
```
申论，练小题，要一道提出对策
申论，练小题，来道贯彻执行
```

**点名话题**：
```
申论，练小题，生态文明的
申论，练小题，2024 年的
```

---

### `申论，批改`

提交答案后触发。**标准四段式输出**：

| 段 | 你会看到 | 怎么用 |
|:---:|:---|:---|
| 一 | 采分点清单（编号 / 标准表述 / 材料细节 / 机构出处） | 知道"标准答案长什么样" |
| 二 | 对照表（采分点 vs **你的答案原文**）+ 覆盖率 | 定位漏了哪些点 |
| 三 | 逐条精批（优 / 要改 / 原表述→升级为 / 改后示范） | **核心**，照着改 |
| 四 | 方法论点评（水平档位 / 核心问题 / 改进动作清单） | 决定下一步练什么 |

**附加**：参考答案、预估得分 + 扣分明细、亮点肯定。

**重要提示**：
- 批改内容**直接显示在对话里**，不用去点文件。
- 同时会生成一份 `申论批改-{卷别}{题号}-{话题}.md` 作为**留档副本**，供日后检索。
- **只有你本人作答才计入台账**。参考答案 / 别人的答案不计入（避免污染统计数据）。

---

### `申论，高频考点`

展示高频考点雷达，可按维度过滤：

```
申论，高频考点                  # 全部
申论，高频考点，按题型           # 只看题型分布
申论，高频考点，按话题           # 只看话题分布
申论，高频考点，生态文明         # 某个话题的考查细节
申论，高频考点，贯彻执行         # 某个题型的考查细节
```

**什么时候用**：备考初期定方向、考前查漏、决定"下一个该练什么"。

---

### `申论，提炼诊断`

观点提炼专项训练。针对「不知道从材料里提炼什么」这个核心痛点。

**流程**：
1. Agent 给你一段材料
2. **你先自己提炼**（写出你认为的要点）
3. 对照讲解**四步提炼路径**：
   - 第 1 步：审题定要素（决定方向）
   - 第 2 步：材料定位三找（找高频词 / 找结论句 / 找主体+动作+结果）
   - 第 3 步：合并同类项（解决"写得碎"）
   - 第 4 步：排序（解决"没条理"）
4. 指出你的提炼在哪一步偏了

**什么时候用**：连续几题批改都显示"漏要点"时，专项突破。

---

### `申论，进度`

展示 `训练记录.md` 的统计：
- 练习台账（日期 / 题号 / 题型 / 话题 / 覆盖率 / 得分 / 失分模式）
- 题型掌握度（已练题数 / 平均覆盖率 / 状态）
- 失分模式频次统计（哪个错犯得最多）
- 待强化清单

**什么时候用**：每练 5 题看一次。

---

### `申论，湖北`

切换 / 查看湖北专项：
- 话题热度排名
- 七大话题高频词
- 命题五大特点
- 湖北 vs 国考的高频词对比（归一化热度）

**什么时候用**：备考湖北省考或多省联考。

## 四、评分标尺怎么读

### 分数构成

```
基础分 =（命中要点数 / 总要点数）× 满分      ← 约 80% 权重
   ↓
逐档扣分（每档有封顶）
   ↓
套用上限与保底条款
   ↓
合理性交叉验证
```

### 三档扣分

| 档位 | 触发条件 | 扣分（10 分题） | 封顶 |
|:---:|:---|:---:|:---:|
| 第一档 · 硬伤 | 做法写成问题 / 要素跑偏 / 写材料外观点 | −0.5 / 条 | 无 |
| 第二档 · 表述精度 | 小标题自创偏离 / 概念抽象化 / 专名遗漏 / 动词强度偏差 | −0.25~0.5 / 处 | 满分 10% |
| 第三档 · 结构性 | 双问未分层 / 层级不齐 / 字数溢出 / 无分条 | −0.25~0.5 / 项 | 满分 10% |

### 上限与保底

| 情形 | 规则 |
|:---|:---:|
| 存在硬伤 | 上限 **85%** |
| **覆盖率 ≥ 80%** | **保底 65%** ⭐ |
| 覆盖率 < 40% | 上限 60% |
| 覆盖率 < 25% | 上限 40% |

### 合理性自检表

算完分数后，Agent 会对照这张表检查是否算错：

| 要点覆盖率 | 合理得分区间 |
|:---:|:---:|
| 100% | 85%~100% |
| 80% | **65%~85%** |
| 60% | 50%~70% |
| 40% | 35%~50% |

若算出的分**落在区间外**，多半是犯了**双重惩罚**（要点分已算，又按表述档重扣一遍）。

## 五、写答案的 8 条铁律

每次批改都会检查这几条：

1. **每条要点 = 小标题 + 具体内容**。小标题 4—8 字，**动词开头**。
2. **能用材料原词就用原词**。申论是"抄"出来的，不是"编"出来的。
3. **要点数量**：200 字题 3—4 条，300—350 字题 4—5 条，450—500 字题 5—6 条。
4. **对策题必须问题与建议一一对应**（题干明说"对应"时尤其严格）。
5. **贯彻执行题三要素**：格式（标题/称谓/落款按文种）+ 身份（我是谁）+ 对象（写给谁）。
6. **不写空话套话**。删掉"我们要高度重视""意义重大"这类无信息量的句子。
7. **带引号的专名该抄就抄**。"GEP 贷""两山银行""数字绿谷"这类专名是"材料熟悉度"的直接证据，性价比最高。
8. **"如何/怎样"类题干，每条必须有做法动词**，不能以问题或目的收尾。

> **第 8 条是"第一号踩坑"**，务必自查：
> 写完每条问一句 —— **"这条里有具体动作吗？"**
> 反例：「缓解融资难、无实体抵押物问题」← 这是**问题**
> 正解：「以生态产品的使用经营权作为质押担保」← 这才是**做法**

## 六、常见问题

### Q：批改说我的答案"覆盖率 80%"，为什么才 6.5 分？

A：因为覆盖率换算成基础分后，还要扣表述与结构的修正分。但**覆盖率 ≥ 80% 有保底 65% 条款**，
所以 10 分题最低 6.5 分。这是设计好的 —— 要写全了就是硬实力，不该被表述问题压到及格线以下。

### Q：为什么我的批改分数比参考答案低这么多？

A：本 skill 采用**从严口径**，但"从严"是指**扣分可核查、有边界、有理由**，
不是把分数往死里压。如果你觉得分数不合理，可以要求 Agent 说明每一笔扣分依据。

### Q：批改后我该做什么？

A：按「**改进动作清单**」（第四段的第 3 项）改。那是按优先级排好的，先改第一项。
然后看「**表述升级表**」，把「原表述 → 升级为」逐个替换，照「改后示范」写出完整句子。

### Q：我批改后把错的段落删掉了，分数怎么反而降了？

A：这是最常见的坑 —— **批改说"这句错了" = "把这句改对"，不是"把这句删掉"**。
删掉会连采分词和线索一起丢。**字数没超就不要压缩**。

### Q：参考答案 / 别人写的答案能批改吗？

A：可以，但**不计入训练台账**（避免污染统计数据）。批改件会标注「第三方答案 / 不计入台账」。

### Q：练多久能看到进步？

A：覆盖率是比较灵敏的指标。一般练 5—8 题后，同类题型的覆盖率会有可观察的提升。
关键不在练得多，在**每次批改后真的改一遍**。

### Q：机构答案 PDF 在哪里？

A：**不在本仓库**。机构答案受版权保护，公开分发有风险。
本仓库保留的是**结构化提炼后的要点库**（`references/真题答案要点库.md`），
保留了"参考答案对照"的核心用法。如需原文请通过正规渠道获取。

## 七、进阶用法

### 组合训练

```
第 1 天：申论，练小题        （练一道归纳概括）
第 2 天：申论，批改          （改昨天的答案）
第 2 天：申论，提炼诊断      （如果批改显示漏要点）
第 3 天：申论，练小题        （再练一道同类题，验证是否改进）
```

### 按话题打透

如果你发现某个话题总失分（比如生态文明），可以：

```
申论，高频考点，生态文明        # 先看考查维度
申论，练小题，生态文明的         # 连续练 3 道同类题
申论，批改                     # 逐道批改
```

### 考前冲刺

```
申论，进度                     # 看失分模式频次，找出 Top 2
申论，高频考点                 # 对照高频考点查漏
申论，练小题                   # 针对性补练 Top 2 对应的题型
```
