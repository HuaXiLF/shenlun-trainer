## 三、文种结构模板（贯彻执行题专用）

### 1. 提纲类（发言/汇报/经验交流/谈话）
```
标题：关于XXX的发言提纲（或"在XXX座谈会上的发言提纲"）
背景：当前……情况/问题（2—3 句）
内容：一、XXX。具体……
      二、XXX。具体……
      （3—5 条，每条"小标题 + 具体做法"）
结语：以上发言，供各位参考/请领导审阅。
```
> 特点：**无需称谓和落款**（提纲是内部材料），但可以有"背景 + 结语"。

### 2. 摘要类（案例摘要）
```
标题：关于XXX的案例摘要
概况：XXX（单位）成立于XX年，持续开展……工作，典型案例有：
案例一——"XXX"：做法 + 成效
案例二——"XXX"：做法 + 成效
案例三——"XXX"：做法 + 成效
```

### 3. 短评类
```
标题：XXXX（4—8 字，含观点倾向，如"金融向善 爱满人间"）
引入：现象/事件描述（2—3 句）
分层评论：这种"XX"，是……（层1）
          这种"XX"，是……（层2）
          这种"XX"，是……（层3）
升华：一句结论
```

### 4. 建议类（工作建议/建议书/实施意见）
```
标题：关于XXX的建议
称谓：尊敬的领导：（建议书需要）
背景：目前存在……问题/意义重大
建议：一、XXX（建议 + 具体措施）
      二、XXX
落款：建议人 / 单位 + 日期
```
> **实施意见**结构：指导思想 + 基本目标 + 主要措施（三段式，2024 地市 3 考过）。

### 5. 报告类（情况报告/汇报材料）
```
标题：关于XXX的情况报告
开头：现将相关情况汇报如下：
一、成效：1.…… 2.……
二、问题/不足：1.…… 2.……
三、建议：1.…… 2.……
```

### 6. 宣传类（宣传材料/展板文稿）
```
标题：XXXX（有吸引力）
称谓/开场（视场合）
亮点分条：一、全面周到的服务…… 二、硬件完备的…… 三、精彩的……
结语：诚挚欢迎各位前来！
```

### 7. 公开信
```
标题：致XXX的一封公开信
称谓：XXX朋友们：
正文：事件背景 + 回应关切（逐条）+ 我们将会怎么做
落款：单位名称 + 日期（必须）
```

### 8. 编者按
```
编者按：近日，在XXX会上，XXX分享了……模式，其经验核心有：
（分条概括核心经验）
希望本期简报能引发更多思考。
```

## 四、结构模板（小题答题骨架）

### 归纳概括
```
【总起句，可选】
一、小标题。具体做法/成效1；具体做法/成效2。
二、小标题。……
三、小标题。……
```

### 提出对策
```
问题：1.…… 2.…… 3.……
建议：1.（对应问题一）…… 2.（对应问题二）…… 3.（对应问题三）……
```
> 或一一配对写：「问题：XXX。对策：XXX。」

### 综合分析（词句理解）
```
这句话的意思是……（总释义）
一、XX层面：指……。具体表现为……
二、XX层面：指……。具体表现为……
因此，我们要……（回扣升华）
```

## 七、动词精度对照表（易混动词辨析）

> 申论用词"差一个字，差一档"。以下为高频易混动词组：

| 弱 | 强 | 差异 |
|:---|:---|:---|
| 促进 | **促成** | "促成"强调主动撮合、使其成功 |
| 缓解 | **解决** | "缓解"只减轻症状，未除根 |
| 提高 | **提升** | "提升"更适合水平、能力、效能 |
| 加大 | **强化** | "强化"更适合举措、监管、支撑 |
| 建立 | **健全/完善** | "健全"含"补齐缺失"，"完善"含"优化已有" |
| 推动 | **催生** | "催生"强调从无到有 |
| 开展 | **开展+具体对象** | 光写"开展"信息量不足 |
| 打造 | **构建** | "构建"更适合体系、格局、机制 |
| 吸引 | **引进/落户** | 看材料用词，"落户"更具体 |
