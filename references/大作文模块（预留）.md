## 二、立意三步法

### 第 1 步：拆解命题句
- 抓**关键词**：命题句里哪两个词是"关系"？（如"力"与"理"、"劣势"与"优势"）
- 抓**逻辑词**："不是……而是……""既要……也要……""只有……才……"——这些直接给出文章骨架。

### 第 2 步：确定"关系类型"
| 类型 | 命题特征 | 文章骨架 |
|:---|:---|:---|
| 递进关系 | A 是 B 的前提 | 分论点层层向上（如"融和"→"融活"） |
| 并列关系 | A 与 B 同等重要 | 分论点平行展开（如"力度""温度""透明度"） |
| 转化关系 | A 可转化为 B | 分论点讲清条件与路径（如"劣势→优势"） |
| 辩证统一 | 看似矛盾实为一体 | 分论点先分说再统一（如"力·理·利"） |

### 第 3 步：定总论点 + 3 个分论点
**分论点必须来自材料**，不能自己编。常用切分维度：

- **主体维度**：个人 / 企业 / 政府 / 社会
- **层面维度**：思想观念 / 制度机制 / 实践行动
- **要素维度**：是什么 / 为什么 / 怎么办

> 真题示范（2023 地市"长期主义"）：
> 分论点 1——追求长期价值，**个人**要保持清醒，建立理性认知框架；
> 分论点 2——追求长期价值，**企业**要树立长远发展格局；
> 分论点 3——追求长期价值，**政府**要树立担当意识。

## 三、结构模板（1200 字标准版）

```
标题（4—12 字，含核心关系词，可含动词）
开头段（150 字）：引命题句 → 释义 → 亮明总论点
分论点 1（250 字）：小标题句 + 阐释 + 举例（材料内）+ 小结
分论点 2（250 字）：同上
分论点 3（250 字）：同上
结尾段（150 字）：呼应开头 + 升华（引用金句）
```

**分论点小标题句式**（高频）：
- 「要……，必须……」
- 「……是……的必然要求」
- 「实现……，关键在于……」
- 「……，既要……也要……」
