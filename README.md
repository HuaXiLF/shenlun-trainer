# 申论训练营 · shenlun-trainer

> 一个给 **AI Agent** 用的国考 / 省考申论小题训练 Skill。
> 解决一件事：**观点提炼能力不够，不知道哪些是高频考点、该往哪个方向写。**

## 为什么做这个

做完申论小题、对照参考答案之后，很多人只知道自己「写得少」，但**说不出具体差在哪**：

- 是没读懂题干？还是找错了材料？
- 是漏了要点？还是要点写成了「问题」而不是「做法」？
- 是表述不标准？还是结构没分层？

市面上不缺答案，缺的是**把「差在哪」拆到可执行动作**的批改。

这个 Skill 干的就是这件事：把「批改」从一个模糊感受，变成**覆盖率 + 逐笔扣分明细 + 失分模式编码**的可核查过程。

## 它到底怎么批改

### 固定四段式（顺序不可调换）

| 段 | 内容 | 回答什么问题 |
|:---:|:---|:---|
| 一 | **采分点清单** | 这题标准答案到底要几个点？哪些必备、哪些开放？ |
| 二 | **对照表** | 你的答案**原文**逐条比对了没有？（含覆盖率统计） |
| 三 | **逐条精批** | 每一条：优在哪 / 要改什么 / 原表述 → 升级为 / 改后示范 |
| 四 | **方法论点评** | 你处在哪个水平档？暴露了哪几个核心问题？下一步改哪个动作？ |

### 评分标尺（v3 校准档）

**核心原则：分数主体由要点覆盖率决定（约 80% 权重），表述与结构只做小幅修正。**

| 档位 | 触发条件 | 扣分（10 分题） | 封顶 |
|:---:|:---|:---:|:---:|
| 第一档 · 硬伤 | 做法写成问题 / 要素跑偏 / 写材料外观点 | **−0.5 / 条** | 无 |
| 第二档 · 表述精度 | 小标题自创偏离 / 概念抽象化 / 专名遗漏 / 动词强度偏差 | **−0.25~0.5 / 处** | **满分 10%** |
| 第三档 · 结构性 | 双问未分层 / 层级不齐 / 字数溢出 / 无分条 | **−0.25~0.5 / 项** | **满分 10%** |

**大分值题放大**：15 分题 ×1.5，20 分题 ×2。

**上限与保底**：
- 存在硬伤 → 上限 **85%**
- **要点覆盖率 ≥ 80% → 保底 65%** ⭐
- 覆盖率 < 40% → 上限 60%；< 25% → 上限 40%

> **为什么要有「保底」条款？**
> 要点写全了就是硬实力。如果因为表述不标准就把分数压到及格线以下，
> 等于传递「表述比要点重要」的错误信号 —— 而申论恰恰是采分点制。
> 详见 [`references/评分标尺与失分模式.md`](references/评分标尺与失分模式.md) 中的「标尺校准史」。

## 八个失分模式（E1—E8）

把最常见的错误编码化，批改时逐条检索，而不是泛泛说「概括不准」：

| 代码 | 失分模式 | 一眼识别 |
|:---:|:---|:---|
| **E1** | 做法写成问题 / 目的 | "缓解融资难" 是**问题**；"以经营权质押担保" 才是**做法** |
| **E2** | 小标题自创偏离 | "吸引企业入驻" 应为 "吸引产业转入" |
| **E3** | 专名遗漏 | 漏掉 "GEP 贷""两山银行" 这类带引号的加分点 |
| **E4** | 双问未分层 | 原因与表现混写 |
| **E5** | 概念抽象化 | 用自己的话替换材料原词，信息量下降（实测最高频） |
| **E6** | 采分词丢失 | 材料原句的关键修饰语被省略 |
| **E7** | 要点层级不齐 | 大概念与小细节并列 |
| **E8** | 主体混淆 | 政府 / 企业 / 群众的做法混为一谈 |

## 命令表

装上之后，你对 Agent 说这些话就能调用：

| 你说 | 它做 |
|:---|:---|
| `申论，练小题` / `申论，出题` | 抽 1 道小题，**只给材料 + 题干，不给答案** |
| `申论，批改` | 按标准四段式批改，给出逐笔扣分明细与得分 |
| `申论，高频考点` | 展示高频考点雷达（按题型 / 话题） |
| `申论，提炼诊断` | 观点提炼专项训练 |
| `申论，进度` | 展示训练记录与薄弱环节 |
| `申论，湖北` | 湖北专项（话题热度、高频词、命题特点） |
| `申论，大作文` | 大作文模块（预留，第二阶段启用） |

也可以直接把答案贴进来让它批改，触发词含「申论」即可。

## 安装

只需要把 `shenlun-trainer` 目录放进你的 skills 目录。**推荐用方式一（下 ZIP）**，
比 `git clone` 快很多。

### 方式一：下载 ZIP（推荐 ⚡）

1. 打开 **https://github.com/HuaXiLF/shenlun-trainer**
2. 点绿色 **Code** 按钮 → **Download ZIP**
3. 解压，把 `shenlun-trainer-main` 文件夹改名成 `shenlun-trainer`
4. 放进 skills 目录（见下方「放哪里」）

> 直链（右键另存为）：
> `https://codeload.github.com/HuaXiLF/shenlun-trainer/zip/refs/heads/main`
>
> 仓库只有 **0.8 MB**，正常网速几秒就好。

### 方式二：git clone

```bash
# 浅克隆（不加 --depth 1 会多下历史，没必要）
git clone --depth 1 https://github.com/HuaXiLF/shenlun-trainer.git
```

### 放哪里

```bash
# WorkBuddy
cp -r shenlun-trainer ~/.workbuddy/skills/
# Windows（PowerShell）：
#   robocopy shenlun-trainer "$env:USERPROFILE\.workbuddy\skills\shenlun-trainer" /E

# Claude Code / 其他兼容宿主
cp -r shenlun-trainer <对应宿主的 skills 目录>/
```

重启会话即可通过「申论，批改」调用。

**首次使用**：把 `训练记录模板.md` 复制到你的工作目录并改名 `训练记录.md`，之后每次批改会自动追加台账。

> ⚠️ **国内网络提示**：GitHub 在国内的直连速度因地区和运营商差异很大，
> 如果 `git clone` 卡住或超时，不是仓库的问题（仓库才 0.8 MB），
> 而是跨境网络问题。建议：
> - 优先用**方式一（ZIP）**，或
> - 使用 GitHub 加速镜像（如 `ghproxy` 类服务），或
> - 让朋友直接把 ZIP 发给你（不到 1 MB，微信/邮件都能发）

## 答案库：多来源交叉比对

`corpus/` 收录 **22—24 年 9 套国考卷全部题目的多来源参考答案** ——
约 **120 个不同来源**（机构 + 个人教师 + 网络 ID），435 个来源标签。

**为什么多来源比单一答案有用？**

申论没有唯一标准答案。单一来源只能告诉你"一种可能"，而多来源交叉比对能看出：

| 现象 | 含义 |
|:---|:---|
| 所有来源都写了 | **采分共识** —— 必写，这是硬分 |
| 少数来源写了 | 加分项，或该来源的个人风格 |
| 同一要点的不同表述 | 直接告诉你哪种表述更规范 |

这正是本 Skill 判断"采分点"的依据。

**来源已去敏**：机构名 → 拼音缩写（`FB` / `HT` / `ZZ` / `ZG`），
个人教师与网络 ID → 匿名编号（`T01` / `T02`…）。对照表见
[`corpus/来源对照表.md`](corpus/来源对照表.md)。



**准确性**：已脚本核验，正文 **零改写、零删减**（详见
[`corpus/README.md`](corpus/README.md) 的核验表）。

## 知识资产速览

### 高频考点雷达

**按题型**（2022—2025 年国考 48 道小题统计）：

| 题型 | 题量 | 占比 | 高频考查维度 |
|:---|:---:|:---:|:---|
| 归纳概括 | 19 | 40% | 做法、成效、问题、原因、启示 |
| 贯彻执行 | 18 | 37% | 提纲类 / 摘要短评类 / 建议类 / 宣传类 / 报告类 |
| 提出对策 | 7 | 15% | 制度、监管、服务、宣传、保障五维 |
| 综合分析 | 4 | 8% | 词句理解（释义 → 分层 → 回扣） |

**按话题**（五年高频，必背素材方向）：

1. **经济产业 · 企业创新**（11 题）：营商环境、制造业冠军、科技创新、产业转移、知识产权
2. **生态文明 · 绿色发展**（9 题）：GEP 生态产品价值、双碳、黄河流域治理、林票制、无废城市
3. **文化传承 · 文化创新**（9 题）：非遗保护、传统文化活化、公共文化服务、文艺创新
4. **民生保障 · 公共服务**（9 题）：就业、基层医疗、政务服务、职工服务
5. **乡村振兴 · 农业农村**（8 题）：乡村运营、高标准农田、乡村文旅、特色农业

### 跨卷规律（省钱关键）

国考**行政执法卷与地市卷常共用材料**：

- 2023 年：第 1 题、第 4 题共用
- 2024 年：第 1 题、第 2 题共用

**练一套等于练两套** —— 优先精练共用材料。
