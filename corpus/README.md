## 统计口径

### 国考部分
- **范围**：2022—2025 年国考申论，每年 3 套卷（行政执法 / 地市级 / 副省级），共 12 套。
- **题量**：每套含问题一～问题四（小题）+ 问题五（大作文/长应用文），小题共 **48 道**。
- **来源**：《申论领跑营 2026 套题实战班》讲义。

### 湖北部分
- **范围**：湖北省考 / 多省联考申论历年真题。
- **词频**：从机构答案全文中统计，共 3724 个词。
- **用途**：备考湖北省考 / 多省联考时判断话题热度与高频表达。

## 版权说明

| 内容类型 | 版权状态 | 是否可分发 |
|:---|:---|:---:|
| 真题**题目原文** | 公开信息（国考公开试题） | ✅ 可收录 |
| 词频**统计结果** | 本项目原创 | ✅ 可分发 |
| 考点**分类与提炼** | 本项目原创 | ✅ 可分发 |
| 机构答案**要点提炼** | 各机构公开答案的结构化提炼 | ⚠️ 仅个人学习，禁商业分发 |
| 机构答案**PDF 原件 / 全文** | 机构版权内容 | ❌ **未收录** |

> **为什么不收录机构答案全文？**
> 粉笔 / 华图 / 站长 / 中公等机构的答案是**受版权保护的商业内容**，
> 其 PDF 原件与全文若公开分发存在侵权风险。
>
> 本仓库的做法是**只保留结构化提炼成果**（即 `references/真题答案要点库.md`），
> 这既保留了「参考答案对照」的核心用法，又避免直接复制机构原文。
>
> 如需查阅机构答案原文，请通过**正规渠道购买对应课程或资料**。

## 数据获取工具（可选）

如果你想自己从 PDF 提取答案文本做统计，可用 Python：

```python
# 需要: pip install pypdf
from pypdf import PdfReader
import re
from collections import Counter

reader = PdfReader("答案.pdf")
text = "\n".join(page.extract_text() or "" for page in reader.pages)

# 统计两字及以上中文词（简易版，生产环境建议用 jieba 分词）
words = re.findall(r"[\u4e00-\u9fff]{2,6}", text)
for word, cnt in Counter(words).most_common(100):
    print(f"{word}\t{cnt}")
```

> 本机无 LibreOffice 时，`pypdf` 足以应付文本型 PDF；
> 若 PDF 是扫描件，需先用 OCR（如 PaddleOCR / 讯飞 OCR）。
