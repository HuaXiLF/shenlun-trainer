## 三、未去敏的标签（非来源名，原样保留）

下列标签**不是来源名**，去敏时有意保留：

| 标签 | 含义 |
|:---|:---|
| `【1】``【2】`…`【5】` | 题号 |
| `【答案一】``【答案二】` | 同一来源的多个版本 |
| `【摘要】``【整合】``【答案】` | 编辑标记 |
| `【4】``【17-18】``【198字，8行】` 等纯数字 | 页码 / 字数标注 |
| `【知乎总结：总结式】``【知乎总结：引入式】` | 结构类型标注 |

## 四、去敏方法与可复现性

去敏由 [`../scripts/desensitize.py`](../scripts/desensitize.py) 完成，规则：

1. 只处理 `【xxx】` 形式的来源标签，**不改动答案正文**
2. **长标签优先匹配**（避免「粉笔单淑玲」被「粉笔」先吃掉）
3. 机构 → 通行拼音缩写
4. 个人教师 / 网络 ID → 匿名编号（同一人不同写法归入同一编号）
5. 非来源标签（题号、页码、编辑标记）→ 原样保留

验证脚本：[`../scripts/check_residual.py`](../scripts/check_residual.py)（扫描机构名残留）。
